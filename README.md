# harrison-p-l.github.io

Harrison Pielke-Lombardo's consulting site, served by GitHub Pages at https://harrison-p-l.github.io.

It's a single static page (`index.html`, no build step). Open it in a browser to preview. Every push to `main` republishes the site.

To use a custom domain, add a `CNAME` file containing the domain and point the domain's DNS at GitHub Pages.
